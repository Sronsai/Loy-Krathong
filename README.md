# 🌸 ลอยกระทงออนไลน์ ริมโขง — โรงพยาบาลปากชม จ.เลย

เว็บแอนิเมชันแบบ motion tween สำหรับรับบริจาคซื้อกระทง ผู้บริจาคกรอกฟอร์ม + แนบสลิป แล้วตัวการ์ตูนชุดไทย
(ชาย/หญิงตามที่เลือก) จะเดินไปรับกระทงที่โต๊ะบนทางเดิน ลงบันไดไปที่แพ แล้วลอยกระทงที่มีป้ายชื่อผู้บริจาค
กระทงไหลวนไปมาบนแม่น้ำโขง และผู้ชมทุกคนเห็นพร้อมกันแบบ real-time

```
index.html            หน้าเว็บหลัก
css/style.css         หน้าตา UI (desktop / มือถือ / โหมดจอใหญ่)
js/config.js          ⚙️ ค่าตั้งค่าฝั่งหน้าเว็บ (API_URL ฯลฯ)
js/scene.js           ฉาก: กระทงบนน้ำ, โคมลอย, พลุ, ระลอกน้ำ, โต๊ะรับกระทง, ป้าย รพ.
js/walkers.js         ตัวการ์ตูนชุดไทย + เส้นทางเดิน
js/app.js             ฟอร์ม, ส่งข้อมูล, รายชื่อเลื่อน, ดึงข้อมูล real-time, โหมดทดลอง
js/promptpay.js       สร้าง QR พร้อมเพย์ตามยอดเงิน
lib/qrcode.js         ไลบรารี QR (qrcode-generator, MIT)
assets/background.jpg ภาพพื้นหลัง 2576x1450
apps-script/Code.gs   Backend (Google Apps Script) บันทึกชีต + เก็บสลิปลง Drive
```

## 1) ทดลองดูทันที (ไม่ต้องติดตั้งอะไร)

ดับเบิลคลิก `index.html` เปิดด้วย Chrome/Edge → จะเข้า **โหมดทดลอง** อัตโนมัติ (มีรายชื่อตัวอย่าง ไม่บันทึกจริง)

| URL | ความหมาย |
|---|---|
| `index.html` | หน้าปกติ (ฟอร์ม + ฉาก + รายชื่อ) |
| `index.html?tv=1` | โหมดจอใหญ่/ไลฟ์ — ซ่อนฟอร์ม แสดง QR ให้ผู้ชมสแกนมาบริจาคทางมือถือ |
| `index.html?demo=1` | บังคับโหมดทดลองแม้เชื่อม API แล้ว (ซ้อมก่อนงาน) |

## 2) ติดตั้ง Backend (Google Apps Script) — ทำครั้งเดียว ~10 นาที

ชีต **Loy Krathong** ถูกเตรียมไว้แล้ว 3 แท็บ:
- **Donations** — ข้อมูลผู้บริจาค 1 แถว/1 รายการ (คอลัมน์ “สถานะ” มี dropdown: รอตรวจสอบ / ตรวจแล้ว / ซ่อน)
- **Summary** — สรุปยอดรวม จำนวนราย แยกขนาดกระทง/เพศ ความคืบหน้าเทียบเป้าหมาย (สูตรอัตโนมัติ)
- **Settings** — ค่าที่เจ้าหน้าที่แก้ได้เองโดยไม่ต้องแตะโค้ด (บัญชีธนาคาร, พร้อมเพย์, เกณฑ์ขนาดกระทง, เป้าหมาย, เปิด/ปิดรับบริจาค)

ขั้นตอน:
1. เปิดชีต → เมนู **ส่วนขยาย › Apps Script**
2. ลบโค้ดเดิม วางเนื้อหาไฟล์ `apps-script/Code.gs` ทั้งหมด → บันทึก
3. (แนะนำ) ⚙️ Project Settings → ติ๊ก “Show appsscript.json” แล้ววางเนื้อหา `apps-script/appsscript.json`
4. เลือกฟังก์ชัน `testSetup` → **Run** → อนุญาตสิทธิ์ (Sheets + Drive) ด้วยบัญชีเจ้าของชีต/โฟลเดอร์ slip
5. **Deploy › New deployment** → ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec` → ใส่ใน `js/config.js` ช่อง `API_URL`
7. ใส่ข้อมูลบัญชีในชีต **Settings** (BANK_NAME, ACCOUNT_NO, ACCOUNT_NAME และ/หรือ PROMPTPAY_ID)

> แก้โค้ด Code.gs ภายหลัง ต้อง **Deploy › Manage deployments › Edit › Version: New version** (URL เดิมใช้ต่อได้)
> แก้ชีต Settings มีผลภายใน ~1 นาที (หรือรันฟังก์ชัน `clearCache`)

สลิปจะถูกบันทึกในโฟลเดอร์ Drive **slip** ชื่อไฟล์ `วันที่-เวลา_รหัส_ชื่อ_ยอดเงิน.jpg` และ**ไม่ถูกแชร์สาธารณะ**

## 3) เผยแพร่ให้ดูออนไลน์แบบ real-time

ระบบ real-time ทำงานแบบ **polling**: ทุกหน้าจอที่เปิดอยู่จะถาม Apps Script ทุก 6 วินาทีว่ามีผู้บริจาคใหม่ไหม
ถ้ามี ตัวการ์ตูนจะเดินไปลอยกระทงบนทุกจอพร้อมกัน (หน่วงไม่เกิน ~6–10 วินาที)

### 3.1 โฮสต์หน้าเว็บ (เลือกอย่างใดอย่างหนึ่ง — ฟรี)
- **GitHub Pages**: สร้าง repo → อัปโหลดทุกไฟล์ (ยกเว้น `apps-script/` ก็ได้) → Settings › Pages › Deploy from branch → ได้ลิงก์ `https://<user>.github.io/<repo>/`
- **Netlify Drop**: ลากโฟลเดอร์ทั้งโฟลเดอร์ไปที่ app.netlify.com/drop → ได้ลิงก์ทันที
- **Cloudflare Pages / Firebase Hosting** ก็ได้เช่นกัน

แล้วใส่ลิงก์นั้นใน `DONATE_URL` ของ `js/config.js` (ใช้ทำ QR ในโหมดจอใหญ่) ทำ short link / QR ไปติดโปสเตอร์ได้

### 3.2 จอใหญ่ในงาน (ริมโขง / หน้า รพ.)
เปิด `https://…/index.html?tv=1` บน PC ต่อทีวี/โปรเจกเตอร์ → กด F11 → คลิก 1 ครั้งเพื่อเปิดเสียงระฆัง
ผู้ร่วมงานสแกน QR มุมจอ บริจาคทางมือถือ แล้วเห็นตัวการ์ตูนของตัวเองเดินไปลอยกระทงบนจอใหญ่

### 3.3 ไลฟ์สดบน Facebook Fan Page (ช่องทางหลัก)

หน้าจอไลฟ์ใช้ลิงก์ `https://…/index.html?tv=1&sound=1&end=23:00`

| พารามิเตอร์ | ผล |
|---|---|
| `tv=1` | ซ่อนฟอร์ม แสดง QR + “หรือกดลิงก์ที่ปักหมุดในคอมเมนต์”, แถบ 🔴 LIVE + ชื่อเพจ + นาฬิกา, แถบข้อความวิ่งด้านล่าง (สลับกับคำอธิษฐานผู้บริจาค), ตัวอักษรใหญ่ขึ้นสำหรับคนดูบนมือถือ |
| `sound=1` | เปิดเสียงระฆังทันที (OBS เล่นเสียงได้โดยไม่ต้องคลิก) |
| `end=23:00` | นับถอยหลังปิดรับบริจาค (หรือใส่ `EVENT_END` ในชีต Settings แทน) เหลือ < 15 นาทีตัวเลขจะกะพริบแดง |

ชื่อเพจบนแถบ LIVE แก้ที่ชีต Settings › `FB_PAGE_NAME`, ข้อความวิ่งแก้ที่ `TICKER_MESSAGES` ใน `js/config.js`

**ตั้งค่า OBS Studio**
1. Scene ใหม่ → Sources › **Browser**
   - URL: ลิงก์ด้านบน · Width **1920** · Height **1080** · FPS 30
   - ติ๊ก **Control audio via OBS** (เพื่อให้เสียงระฆังเข้าไลฟ์)
2. Settings › **Video**: Base และ Output = 1920×1080, 30 FPS
3. Settings › **Output** (Advanced): Encoder x264 หรือ NVENC · Rate control **CBR** · Bitrate **4500–6000 Kbps** · Keyframe interval **2 s** · Audio 128 Kbps
4. Settings › **Stream**: Service = Facebook Live → วาง Stream key

**ฝั่ง Facebook**
1. เปิด facebook.com/live/create บนคอมด้วย Chrome → เลือกโพสต์ในนาม **เพจ รพ.** → Streaming software
2. Advanced settings → เปิด **Persistent stream key** (ใช้คีย์เดิมได้ทุกรอบ ไม่ต้องคัดลอกใหม่)
3. ใส่ชื่อไลฟ์/คำอธิบาย (ด้านล่าง) → ใน OBS กด **Start Streaming** → รอภาพขึ้นใน Facebook แล้วกด **Go live**
4. ปักหมุดคอมเมนต์ลิงก์บริจาคทันทีที่ไลฟ์เริ่ม

**ข้อความตัวอย่าง (คำอธิบายไลฟ์ / คอมเมนต์ปักหมุด)**
```
🌸 ลอยกระทงออนไลน์ ริมโขง — ร่วมบุญซื้อกระทง สมทบทุนโรงพยาบาลปากชม จ.เลย
👉 ร่วมบุญได้ที่ https://…(ลิงก์หน้าบริจาค)
กรอกชื่อ เลือกเพศ ใส่ยอด แนบสลิป แล้วดูตัวการ์ตูนของคุณเดินไปลอยกระทงในไลฟ์นี้ได้เลย
กระทงเล็ก 20 บาท+ | กลาง 100 บาท+ | ใหญ่ 500 บาท+ (มีพลุ 🎆)
```

**ข้อควรรู้**
- Facebook ไลฟ์ผ่านโปรแกรมได้สูงสุด **8 ชั่วโมง/ครั้ง** — ถ้านานกว่านั้นให้หยุดแล้วเริ่มไลฟ์ใหม่ (คีย์ถาวรใช้ต่อได้)
- ภาพบนไลฟ์ช้ากว่าเว็บประมาณ 15–40 วินาที (ปกติของ Facebook)
- **ห้ามเปิดเพลงที่มีลิขสิทธิ์** Facebook อาจปิดเสียงหรือหยุดไลฟ์ — ใช้เสียงระฆังในระบบ หรือเพลงปลอดลิขสิทธิ์
- คอมที่ไลฟ์: อินเทอร์เน็ตอัปโหลด ≥ 6 Mbps (เสียบสาย LAN ดีที่สุด), ปิดโหมด Sleep/อัปเดต Windows, เสียบปลั๊กไฟ
- ซ้อมก่อนวันงานโดยตั้งไลฟ์เป็น **Only me** ด้วย `?tv=1&demo=1`
- อยากไลฟ์ YouTube พร้อมกัน: ติดตั้งปลั๊กอิน **Multiple RTMP outputs** ใน OBS

## 5) งานของเจ้าหน้าที่ระหว่างงาน
- เปิดชีต Donations ตรวจสลิป (คลิกลิงก์สลิป) แล้วเปลี่ยนสถานะเป็น **ตรวจแล้ว**
- ชื่อไม่เหมาะสม/สลิปปลอม → เปลี่ยนเป็น **ซ่อน** (หายจากจอและไม่นับยอดภายใน ~5 วินาที)
- ต้องการให้ขึ้นจอเฉพาะรายการที่ตรวจแล้ว → Settings: `REQUIRE_APPROVAL = TRUE`
- ปิดรับบริจาคหลังจบงาน → Settings: `DONATION_OPEN = FALSE`
- ดูยอดรวมที่แท็บ **Summary**

## 6) ข้อแนะนำเพิ่มเติม
- **ตรวจสลิปอัตโนมัติ**: ต่อ API ตรวจสลิป (เช่น SlipOK, EasySlip) ใน `doPost` เพื่อกันสลิปซ้ำ/ปลอม
- **ใบเสร็จลดหย่อนภาษี (e-Donation)** ต้องใช้เลขประจำตัวผู้เสียภาษี 13 หลัก — ฟอร์มนี้ไม่เก็บเพื่อลดความเสี่ยงข้อมูลส่วนบุคคล
  ให้เจ้าหน้าที่โทรกลับจากเบอร์ที่ผู้บริจาคติ๊ก “ต้องการใบอนุโมทนาบัตร”
- **PDPA**: มีช่องยินยอม และตัวเลือก “ไม่ประสงค์ออกนาม”; เบอร์โทรและสลิปเห็นเฉพาะเจ้าหน้าที่ — ควรประกาศนโยบายความเป็นส่วนตัวของ รพ. ไว้ในหน้าเว็บ
- **รองรับผู้ชมจำนวนมาก**: Apps Script รับคำขอพร้อมกันได้จำกัด (ประมาณ 30 คำขอ/สคริปต์) และมีแคช 5 วินาทีช่วยแล้ว —
  ถ้าคาดว่าผู้ชมเปิดพร้อมกันหลายร้อยคน ให้เพิ่ม `POLL_MS` เป็น 10000–15000 หรือให้คนส่วนใหญ่ดูผ่านไลฟ์ (OBS) แทน
  ถ้าต้องการรองรับหลักพันคนขึ้นไป ค่อยย้ายฝั่ง real-time ไป Firebase Realtime Database
- **ทดสอบก่อนวันงาน**: ใช้ `?demo=1` ซ้อม และทดลองบริจาคจริง 1–2 รายการ แล้วลบแถวทดสอบในชีต

## 7) การโอนเงิน (QR พร้อมเพย์ e-Donation ใส่ยอดอัตโนมัติ)
- ระบบใช้ข้อมูลจาก QR e-Donation ของ รพ. (`edonation.jpg`) แล้ว **ฝังยอดเงินที่ผู้บริจาคเลือก** ลงใน QR ให้ทันที — สแกนแล้วยอดขึ้นเอง ไม่ต้องพิมพ์
- ผู้รับเงินเป็นปลายทางเดิมของ QR e-Donation (Biller ID เดิม) ผู้บริจาคจึงยังลดหย่อนภาษีผ่านระบบ e-Donation ได้ตามปกติ (ยินยอมส่งข้อมูลในแอปธนาคาร)
- ผู้ใช้มือถือเครื่องเดียว: กด **💾 บันทึก QR ลงเครื่อง** → เปิดแอปธนาคาร › สแกน › เลือกรูปจากอัลบั้ม → โอน → แคปสลิปมาแนบ
- ข้อมูล QR อยู่ที่ `THAIQR_PAYLOAD` (js/config.js และชีต Settings) ถ้า รพ. เปลี่ยน QR ให้ถอดค่าใหม่มาใส่
- ⚠️ ก่อนเปิดใช้จริง ให้ทดลองสแกนโอน 1 บาท–20 บาทด้วยแอปธนาคาร 2–3 ธนาคาร ตรวจว่าชื่อผู้รับเป็น “โรงพยาบาลปากชม” และยอดถูกต้อง
